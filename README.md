# 今天吃什么

南京大学《人机交互课程》小组项目。当前处于用户研究与问题界定阶段，关注用户如何从需要解决一顿饭走到最终选择，以及继续浏览、比较和停止选择的原因。

## 资料导航

| 内容 | 位置 | 使用说明 |
| --- | --- | --- |
| 个人外卖访谈执行稿 | [访谈提纲](docs/正式材料/访谈提纲.md) | 当前整理的正式材料 |
| 调研设计与问卷草案 | [用户调研设计](docs/用户调研设计/) | 包含外卖、堂食及两者切换的扩展研究方案 |
| 文献阅读总结 | [Markdown 版](docs/文献/人机交互文献总结.md) · [Word 版](docs/文献/人机交互文献总结.docx) | Markdown 为可协作编辑的正文，Word 为阅读和交付版本 |
| 文献书目信息 | [文献索引](docs/文献/人机交互文献索引.csv) | 保留 DOI、公开链接和阅读范围 |

现有两份访谈提纲的场景范围不同：正式材料聚焦个人外卖，调研设计草案包含个人堂食。执行研究时应先统一所使用的版本，避免混用题目和统计口径。

## 协作方式

- `main`：经小组确认的阶段成果。
- `develop`：日常协作与材料整合。
- `docs/<成员>-<主题>`、`feature/<成员>-<主题>`、`fix/<成员>-<主题>`：从 `develop` 创建的任务分支，通过 PR 合并回 `develop`。
- 阶段验收后，通过 PR 将 `develop` 合并到 `main`。

具体命令与提交约定见 [协作指南](CONTRIBUTING.md)。

## 资料边界

仓库保存可供小组共享的材料。个人文献库定位信息、绝对文件路径、账户配置、原始录音、联系方式和未脱敏的访谈记录保留在仓库外，或存放在已忽略的 `.local/`、`private/`、`data/raw/` 目录。

文献索引使用 DOI 和公开原文链接定位资料。提交前运行 `python scripts/check_local_references.py`；GitHub 也会自动检查提交中的本机路径和文献管理器内部链接。
